### 🚀 Quick Start

#### Prerequisites
- Java 21+ and Maven


#### Installation

1. **Clone the repository**
```bash
git clone https://github.com/galafis/Java-Security-Framework.git
cd Java-Security-Framework
```

2. **Build the project**
```bash
mvn clean install
```

#### Running

```bash
mvn spring-boot:run
```
